# ReadX Audio Assets

Drop all `.mp3` sound effect files into this directory.

## Required files

| File | Moment |
|---|---|
| `level-up.mp3` | User reaches a new reader level |
| `session-complete.mp3` | Focus timer session ends |
| `feather-earned.mp3` | Feather tokens awarded |
| `quote-saved.mp3` | Quote saved successfully |
| `page-turn.mp3` | EPUB page turn |
| `book-open.mp3` | Book opened for reading |
| `timer-start.mp3` | Focus timer started |
| `owl-hoot.mp3` | AI Owl FAB tapped |
| `tab-click.mp3` | Bottom nav tab switch |
| `auth-success.mp3` | Login / register success |
| `error.mp3` | Error state |
| `notification.mp3` | New notification |
| `purchase.mp3` | Reward store purchase |

## Free sources
- https://freesound.org
